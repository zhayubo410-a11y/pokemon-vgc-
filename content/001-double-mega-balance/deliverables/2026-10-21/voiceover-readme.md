# 单段连续口播配音

- 输入：口播稿-单段连续配音版.txt，3310字符，与确认口播逐字一致，无段落换行或SRT时间码。
- 成品：配音-中文中低音男声.mp3；另保留PCM WAV母带。
- 语言与音色：中文普通话，中低音男声，Kokoro / zm_yunyang，语速1.0。
- 实际MP3时长：7分42.9秒；24kHz单声道，128kbps。
- 连续上下文合成，不按逐条SRT配音。模型内部使用重叠上下文窗口衔接，标点保留短停顿；针对长静音作检测与必要收紧。

本次原文没有重写。专名使用中文分词和读音，英文缩写及作者名走英文发音前端。合成语音不是人工录音。已验证可解码、时长、有限波形及静音，未逐字人工听校。

旧SRT仍属估算，不能当作本音频的精确字幕。phoneme-timing.json记录的是后处理前音频的模型音素时间；若收紧了静音，需要以最终音频再对齐。
